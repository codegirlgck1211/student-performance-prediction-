# Student Performance Prediction

## 📌 Project Overview
This project predicts student marks based on study hours using Linear Regression in R.

## 🎯 Objective
To analyze the relationship between study hours and student performance and build a predictive model.

## 🛠 Tools & Technologies
- R Programming
- Linear Regression
- Data Visualization 
- Statistical Analysis

## 📊 Dataset
Synthetic dataset with 100 student records containing:
- Hours studied
- Marks obtained

## 🔍 Steps Performed
1. Data generation and cleaning
2. Exploratory Data Analysis (EDA)
3. Train-Test split
4. Model training using Linear Regression
5. Model evaluation (MAE, RMSE, MAPE)
6. Visualization of Actual vs Predicted values

## 📈 Results
- Strong positive correlation between study hours and marks
- Model shows good predictive performance
- RMSE indicates acceptable prediction error

## 📁 Files
- `student_model.R` → Main code file
- `README.md` → Project documentation

## ✅ Conclusion
The model successfully predicts student performance based on study hours.  
This project demonstrates the application of regression analysis in data science.
